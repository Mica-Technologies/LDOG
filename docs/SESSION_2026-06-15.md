## 2. What we did (chronological, with commits)

### 2a. FSR2 in-motion flicker — attempted, NOT fixed

- `f1f7669` — bilinear blit when TAA off (kill Lanczos ring). No change.

### 2b. GLSL preprocessor for active DRAWBUFFERS — `178b262`
- New `GlslPreprocessor` (`render/shaderpack/`): `#define`/`#undef`/`#ifdef`/
  `#ifndef`/`#if`/`#elif`/`#else`/`#endif` + a real constant-expression parser
  (`defined()`, int literals, `! && || == != < > <= >= + - * /`, parens).
- `ShaderPackRuntime.tryCompile` strips inactive branches **before**
  `parseDrawBuffers`, so the first *surviving* directive is the active one.
  Fixes the old "first textual directive wins" bug that picked dead branches and
  mis-mapped `gl_FragData[i] → colortex`.
- Unit-tested: `GlslPreprocessorTest` (13 cases).

### 2c. OptiFine builtin macro injection — `e337536`
- New `ShaderMacros`: builds `MC_VERSION=11202`, `MC_GL_VERSION`,
  `MC_GLSL_VERSION`, `MC_OS_*`, `MC_GL_VENDOR_*`, `MC_GL_RENDERER_*`,
  `MC_RENDER_QUALITY/SHADOW_QUALITY/HAND_DEPTH` from the live GL context + OS,
  injected as `#define`s after `#version`.
- The **same** macro map seeds `GlslPreprocessor`, so DRAWBUFFERS resolution sees
  exactly what the driver compiles. Verified live: user's RTX 3090 reports
  `MC_GL_VERSION=460, MC_GLSL_VERSION=460` (accurate, matches what OF would emit).
- Deliberately omits `MC_NORMAL_MAP`/`MC_SPECULAR_MAP` (those samplers read black
  → packs should take their no-map path).
- Unit-tested: `ShaderMacrosTest` (8 cases).

### 2d. Uniform parity — `d97568a`
- Added `previousCameraPosition` (motion-blur/temporal packs) and made
  `frameTimeCounter` wrap at 3600 s like OF.

### 2e. Per-frame GL error flood — drain + localize — `d6db2c8`, `c628fc7`
- New `PipelineGlProbe.drain(stage)`: drains the GL error queue at each stage
  boundary (so nothing reaches MC's `@ Post render` check) and logs the offending
  stage **once** per (stage, code). Because each boundary drains, the first stage
  to report is exactly where the error is born.
- Probes placed in frame order: `frame-start (upstream)`, `shadow:depth-render`,
  `shadow:matrix-restore`, `gbuffer:beginWorld`, `gbuffer:bind:<category>`,
  `gbuffer-world`, `composite`/`composite (multi-write)`, `fsr2`, `pass:<id>`.
- Fixed the multi-write composite leak's root cause (stale FBO attachment →
  feedback loop) by detaching all color attachments before each stage.
- Quieted the hundreds of "no active uniform" WARNs for pack programs
  (`ShaderProgram.quietMissingUniforms()`) — they use only a uniform subset by
  design.

### 2f. Pack-declared colortex buffer formats — `caaf2ae`, `60940e3`
- New `ShaderColortexFormats`: parses `const int colortexNFormat = …;` and the
  legacy `gauxN` (→ colortex4..7) declarations → GL internal formats with matching
  `glTexImage2D` format/type.
- `ShaderPackRuntime` accumulates formats across stages; `ShaderPackGbufferManager`
  (aux attachments) AND the multi-write composite scratch (`mrtCur`/`mrtAlt`)
  allocate with the declared format. RGBA8 fallback when undeclared/unrecognised.
- colortex0 stays the shared scene texture (already RGBA16F ⊇ R11F_G11F_B10F under
  the HDR pipeline).
- Unit-tested: `ShaderColortexFormatsTest` (7 cases).

### 2g. BSL dark/invisible — temporal history persistence — `882be10`
- **Diagnosis:** both BSL v8.2 and v10.1 default terrain to `DRAWBUFFERS:0`
  (resolution correct). The real cause is temporal history: BSL's TAA reads
  `colortex2` as cross-frame history (`textureCatmullRom(colortex2, prvCoord)`).
  **v10.1 enables TAA by default, v8 does not** — which is why v10.1 is *invisible*
  and v8 only *dark*. We cleared/re-seeded every aux buffer each frame → history
  permanently zero → TAA blends geometry to black while skipping sky pixels →
  "invisible except sky."
- **Fix:** the composite pass now only re-copies buffers the `gbuffers_*` programs
  actually wrote (per-colortex mask = union of their resolved DRAWBUFFERS,
  colortex0 always included). Composite-only buffers (TAA history, accumulation)
  persist frame-to-frame (their `mrtCur` texture already survives between frames;
  we stopped clobbering it). This is the load-bearing half of OF's
  `colortexNClear = false`.
- Added a one-time per-pack diagnostic dumping each stage's resolved DRAWBUFFERS +
  declared formats (`grep "resolved buffers" run/logs/latest.log`).

## 5. Known open issues / parked work

### 5a. FSR2 in-motion flicker — UNRESOLVED (parked)
- Config: `FSR2 + TAA off + internalRenderScale 0.75 + HDR pipeline`, flickers
  while flying **even with no shader pack**.
- Ruled out: FSR2 history weight, TAA-only jitter, axis-snapped normals, bilinear
  blit (no ringing) — none fixed it. **The FSR2 resolve kernel is NOT the cause.**
- Next-session plan: instrument properly. (a) Test `internalRenderScale = 1.0` to
  rule out the scaled-render/upscale path entirely. (b) Disable the post pipeline
  entirely to confirm pipeline-vs-vanilla. (c) Then bisect features. Do NOT keep
  guessing FSR2.

### 5b. Remaining BSL-specific parity gaps (if it still looks off after `882be10`)
- **Custom textures**: `texture.noise=tex/noise.png`,
  `texture.composite.depthtex2=tex/dirt.png` — we don't bind pack custom textures
  (depthtex2 reads our depth alias instead of dirt.png).
- **Per-program alpha test**: `alphaTest.gbuffers_terrain=GREATER 0.1` etc. — OF
  applies these; we rely on MC's fixed-function alpha test.
- **colortex8/9** (used only with `MULTICOLORED_BLOCKLIGHT`, off by default) — our
  MAX_AUX is 7 (colortex0..7), so 8/9 aren't allocated.
- **Shader-options GUI** — packs run at their in-source `#define` defaults; there's
  no UI to toggle pack options (ADVANCED_MATERIALS, TAA, etc.). This is the biggest
  remaining structural gap. Note: BSL v10.1's default TAA can't currently be turned
  off by the user, which forced the temporal-persistence fix to matter.
- **Motion vectors for BSL TAA reprojection** — TAA reads `colortex2` history with a
  reprojected coord; if our camera-MV/`gbufferPrevious*` matrices are off, ghosting
  or smear may appear even with persistence working.

### 5c. Other deferred-pack gaps (longstanding)
- Sky NOT dispatched through `gbuffers_skybasic/skytextured` (vanilla sky into
  colortex0 instead).
- Custom vertex attrs (`mc_Entity`, `at_tangent`, `at_midBlock`) degrade to zero →
  no waving plants / water ID / parallax.
- Normal/specular maps feed black (`MC_NORMAL_MAP`/`MC_SPECULAR_MAP` intentionally
  undefined).
- Shadow bias/softness visual tuning.
